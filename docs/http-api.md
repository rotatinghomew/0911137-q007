# 本地接口

- `GET /api/catalog`：资料名称、可选业务范围、业务时点范围、表计数与资料指纹。
- `GET /api/view`：当前摘要，可选 `cutoff` 整数和 `group` 业务范围；未知筛选项返回 400。
- `GET /api/model`：在当前筛选范围上估计的选择模型，含价格系数与标准误、商品 ASC、门店外部项、拟合优度、识别诊断与共同可选支撑矩阵。
- `GET /api/validation`：按顾客分组的 K 折交叉验证、时间外推、三个基准（选择模型/等概率/仅截距）的对数损失与命中率，以及泄漏自检结果。
- `POST /api/scenario`：情景试算。请求体为 `{"options": {"cutoff": 整数, "group": "范围"}, "scenario": {...}}`；`scenario` 可含 `removals`（商品标识列表）、`price_changes`（商品到正价格的映射）、`additions`（含 `item`/`family`/`size`/`price` 的上新列表），三类动作可组合。返回基线与情景的期望销量/经营额（含 90% 区间）、撤下商品去向三分（有支撑同店商品/无观测支撑替代/直接不买）、蚕食分解与无支撑提示。动作冲突或字段非法返回 400。
- `GET /api/source?table=visits`：按实际资料表名称查询原始记录；不存在的表返回 404。
- `POST /api/analyses`：JSON 对象包含 `title` 与 `options`，重新计算并保存，成功返回 201。`options` 与当前摘要的筛选结构相同。
- `GET /api/analyses`：只返回版本目录及资料指纹。
- `GET /api/analyses/{id}`：返回保存的完整结果，不重新计算。

## 情景结果的去向口径

撤下商品 `r` 的期望销量按三类归因，三类之和等于其基线期望销量（质量守恒）：

- `to_items_supported`：承接商品与 `r` 在历史上至少共同可选过一次，或属于本次显式上新；替代有观测/假设支撑。
- `to_items_unsupported`：同店经营但与 `r` 从未共同可选的承接商品，仅为 MNL 的 IIA 外推，页面高亮且不计入精确替代率。
- `to_outside`：直接不买，回流到外部选项。

所有期望量都基于 BHHH 协方差的固定种子参数抽样（默认 200 次），给出点估计与 5%/95% 分位；新商品在此之外叠加层级先验方差。无观测不表示为零值，而是以宽区间和 `support_flags` 显式标注。

API 的 `rows` 是领域行，`summary` 是当前汇总，`notes` 是业务口径提示，`options` 是实际采用的筛选值。无记录使用空列表，不能把无观测偷偷表示为有效的零值。错误 JSON 的 `error` 可直接在页面反馈。

这是本地单用户应用，不包含认证与外网部署设置。默认只监听回环地址，容器中可显式监听所有接口，但宿主机端口建议只绑定回环地址。
